SEO উন্নত ফাইল — আপলোড নির্দেশনা
================================

এই প্যাকেজে যা আছে:
1. index.html     → শক্তিশালী Description + Schema (Place, Organization, sameAs)
2. gallery.html   → উন্নত Description
3. sitemap.xml    → admin বাদ, lastmod যোগ, priority ঠিক
4. robots.txt     → admin.html ব্লক (Google যেন অ্যাডমিন ইনডেক্স না করে)

কী করবেন (Android):
1. GitHub → আপনার রিপো → Add file → Upload files
2. এই ৪টা ফাইল একসাথে সিলেক্ট করে আপলোড করুন
3. Commit changes
4. ২-৩ মিনিট পর সাইট চেক করুন

গুরুত্বপূর্ণ:
- অন্য কোনো ফাইল মুছবেন না
- admin.html আগের মতোই থাকবে (শুধু Google তাকে ইনডেক্স করবে না)
- ডিজাইন ও ফিচার একদম অপরিবর্তিত

আপলোডের পর Google Search Console এ:
- Sitemaps সেকশনে গিয়ে আবার sitemap.xml সাবমিট/রিফ্রেশ করুন
- URL Inspection দিয়ে হোমপেজ ও gallery.html Inspect → Request Indexing করুন
