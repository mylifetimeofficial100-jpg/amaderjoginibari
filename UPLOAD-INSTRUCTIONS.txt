ফাস্টার হোমপেজ — আপলোড নির্দেশনা
================================

এই প্যাকেজে যা আছে:
- index.html  (শুধু প্রথম স্লাইড প্রিলোড যোগ করা হয়েছে, ডিজাইন অপরিবর্তিত)
- slide_01.jpg থেকে slide_11.jpg  (অপটিমাইজড — সাইজ অনেক কমেছে)

কী করবেন:
1) এই ফোল্ডারের সব ফাইল GitHub রিপোতে আপলোড করুন
2) পুরনো slide_01.jpg ... slide_11.jpg এবং index.html রিপ্লেস হবে
3) অন্য কোনো ফাইল (gallery.html, photo_*, admin.html, img_*) মুছবেন না / ছুঁবেন না

ধাপ (Android):
- GitHub → আপনার রিপো → Add file → Upload files
- একসাথে সিলেক্ট করুন: index.html + সব slide_01 থেকে slide_11
- Commit changes
- ২-৩ মিনিট অপেক্ষা করুন
- সাইট খুলে চেক করুন
